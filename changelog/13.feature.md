Added `scripts/run_rcmip3.py` — a unified RCMIP3 protocol runner that
dispatches one or more SCM adapters (currently FaIRv2 and CICEROSCMPY2)
across the CMIP6 SSPs, CMIP7 `scen7-*` markers, and `esm-flat*`
idealised family, streaming per-(model, scenario) output to a netCDF
tree on disk via `NetCDFChunkWriter`. Scenarios are resolved through
`load_rcmip3_emissions` (PR #12), so the same CLI covers any
RCMIP3 protocol ID the loader knows about. `--scenario-set
{ssps,scen7,flat,historical,all}` gives convenience bundles; pass
`--scenarios <ids...>` for explicit subsetting.

Supersedes and removes the per-model demo scripts
`scripts/run_rcmip_fair2.py` and `scripts/run_rcmip_ciceroscm_py2.py`;
both were near-mirrors of each other with no shared code, and neither
persisted full timeseries output for downstream notebook consumption.
