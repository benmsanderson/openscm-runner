- Added `parallel_models` and `max_model_workers` keyword arguments to `openscm_runner.run.run`. When `parallel_models=True` (default), the climate models requested in `climate_models_cfgs` are dispatched concurrently via a top-level `concurrent.futures.ProcessPoolExecutor` instead of running serially one after another. `max_model_workers` caps the top-level pool size (default 8). Pass `parallel_models=False` to restore the previous serial dispatch (useful for debugging or when downstream code depends on a specific model dispatch order). The change has no effect when only one model is requested.
