- Added an optional `output_writer` keyword argument to `openscm_runner.run.run`. When supplied, each model's result is split into per-(climate_model, scenario) chunks and dispatched to the writer as the model finishes, rather than accumulated into a single in-memory `scmdata.ScmRun`. Instead of an `ScmRun`, the run returns a lightweight `openscm_runner.RunResult` carrying the written file paths plus summary metadata (`models`, `scenarios`, `n_runs`). Default behaviour (no writer) is unchanged. A shipped `openscm_runner.NetCDFChunkWriter(output_dir)` writes the chunks to netCDF at `{output_dir}/{climate_model}/{scenario}.nc` using `scmdata.ScmRun.to_nc` (requires the `netCDF4` package). Use `RunResult.iter_chunks()` to read chunks back lazily without holding the whole ensemble in memory. Motivated by Scenario Compass-scale ensembles that would otherwise OOM a typical compute node.
