- Added a `FaIRv2` adapter for FaIR 2.x as a sibling to the existing `FaIR` (FaIR 1.6) adapter. Registered under `model_name="FaIRv2"`; the existing adapter is unchanged. First version supports native-calibration mode only: each per-model cfg dict carries a `native_calibration` sidecar key pointing at a FaIR 2.x calibration bundle (a directory of CSVs as published on Zenodo, e.g. https://zenodo.org/records/18828694), with an optional `member_indices` sidecar key that subsets the parameter posterior. Currently emits Surface Air Temperature Change, total Effective Radiative Forcing, and Atmospheric Concentrations|CO2. Real `ScmRun` -> FaIR emissions conversion, the full output variable mapping, and translated-cfg mode (per-member dicts, for parity with the FaIR 1.6 adapter) are follow-up work.
