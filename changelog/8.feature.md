Added `CICEROSCMPY2` adapter wrapping CICERO-SCM v2.1.0's native `DistributionRun` ensemble API as a sibling to the existing `CICEROSCMPY` (v1.1.x) adapter. Supports two operating modes — splice (user emissions overlaid on bundled ssp245 historical) and bundle (`cicero_bundle_dir`, the Marit RCMIP-aligned setup) — with concentration-driven mode and per-scenario `emstart` auto-detection. Output variable requests are validated against the canonical openscm-name allowlist up-front so unsupported variables raise a categorised `ValueError` instead of being silently dropped from the result. A `ciceroscmpy2 = ["ciceroscm"]` pyproject extra is added, mutually exclusive with `ciceroscmpy` at install time.
